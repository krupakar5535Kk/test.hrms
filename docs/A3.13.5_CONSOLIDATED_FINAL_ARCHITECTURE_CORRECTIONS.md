- **Root Cause:** Historical drafting divergence from PRD v1.8 §7 and §11.

  3. **Core Shift Window:** **10:00 AM to 6:00 PM (10:00:00 to 18:00:00 local office time)**.

  5. **Statutory Lunch Break:** **1:00 PM to 2:00 PM (13:00:00 to 14:00:00 local office time)** = 60 minutes.

     - Morning Late Grace: Up to 15 minutes (arrival by 10:15:00 is not penalized with disciplinary strikes, but payable minutes accumulate from actual check-in unless authorized).

### Finding A3: Unique Scheduled Leave-Day Counting
- **Defect Identified:** A3.13.4 used `generate_series` joined with `leave_applications` without enforcing uniqueness, causing overlapping approved leave records to multiply deducted leave days.
- **Corrected Design & SQL:**
  Unique scheduled working days are calculated using `SELECT DISTINCT la.employee_id, d::date` before aggregating:
  ```sql
  -- Unique eligible scheduled leave days calculation excluding weekly offs and declared holidays
  WITH distinct_leave_dates AS (
    SELECT DISTINCT
      la.employee_id,
      d::date AS calendar_date
    FROM public.leave_applications la
    CROSS JOIN LATERAL generate_series(
      GREATEST(la.start_date, v_period.start_date),
      LEAST(la.end_date, v_period.end_date),
      '1 day'::interval
    ) AS d
    WHERE la.status = 'APPROVED'
      AND la.organization_id = v_period.organization_id
      AND la.start_date <= v_period.end_date
      AND la.end_date >= v_period.start_date
  ),
  eligible_leave_days AS (
    SELECT
      dld.employee_id,
      COUNT(DISTINCT dld.calendar_date) AS scheduled_leave_days
    FROM distinct_leave_dates dld
    LEFT JOIN public.holidays h 
      ON h.organization_id = v_period.organization_id 
     AND h.holiday_date = dld.calendar_date
     AND h.is_optional = FALSE
    WHERE EXTRACT(ISODOW FROM dld.calendar_date) <> 7 -- Exclude Sundays
      AND h.id IS NULL                                -- Exclude Public Holidays
    GROUP BY dld.employee_id
  )
  SELECT COALESCE(eld.scheduled_leave_days * 420, 0)::int
  INTO v_unpaid_leave_mins
  FROM eligible_leave_days eld
  WHERE eld.employee_id = v_emp.employee_id;
  ```

### Finding A4: Exhaustive and Mutually Exclusive Day/Minute Partition & Non-Double-Deduction Proof
- **Defect Identified:** Need formal proof that all daily states partition every calendar minute without double deduction.
- **Relational Partition Proof:**
  Let the period calendar duration for an employee be $D = \{d_1, d_2, \dots, d_n\}$. Every calendar date $d \in D$ maps to exactly ONE mutually exclusive attendance classification $C(e, d)$:
  
  $$\forall d \in D, \quad C(e, d) \in \{\text{WEEKLY\_OFF}, \text{PUBLIC\_HOLIDAY}, \text{ON\_LEAVE}, \text{PRESENT\_FULL}, \text{PRESENT\_PARTIAL}, \text{INCOMPLETE\_PAIR}, \text{ABSENT}\}$$

  **Priority Evaluation Tree:**
  1. If $\text{ISODOW}(d) = 7 \implies \mathbf{WEEKLY\_OFF}$ ($M_{\text{sched}} = 0, M_{\text{pay}} = 0, M_{\text{unpaid}} = 0$).
  2. Else If $\exists h \in \text{holidays}: h.\text{date} = d \land \neg h.\text{is\_optional} \implies \mathbf{PUBLIC\_HOLIDAY}$ ($M_{\text{sched}} = 0, M_{\text{pay}} = 0, M_{\text{unpaid}} = 0$).
  3. Else If $\exists l \in \text{leave\_apps}: l.\text{status} = \text{'APPROVED'} \land d \in [l.\text{start}, l.\text{end}] \implies \mathbf{ON\_LEAVE}$ ($M_{\text{sched}} = 420, M_{\text{pay}} = 0, M_{\text{unpaid}} = 420$).
  4. Else If $\exists a \in \text{attendance\_days}: a.\text{date} = d$:
     - If $a.\text{in} \text{ IS NOT NULL} \land a.\text{out} \text{ IS NOT NULL} \land a.\text{out} > a.\text{in}$:
       - If $a.\text{net\_payable\_minutes} \ge 420 \implies \mathbf{PRESENT\_FULL}$ ($M_{\text{sched}} = 420, M_{\text{pay}} = 420, M_{\text{unpaid}} = 0$).
       - If $a.\text{net\_payable\_minutes} < 420 \implies \mathbf{PRESENT\_PARTIAL}$ ($M_{\text{sched}} = 420, M_{\text{pay}} = a.\text{net\_payable\_minutes}, M_{\text{unpaid}} = 420 - a.\text{net\_payable\_minutes}$).
     - Else (Inverted timestamps, missing in, or missing out) $\implies \mathbf{INCOMPLETE\_PAIR}$ ($M_{\text{sched}} = 420, M_{\text{pay}} = 0, M_{\text{unpaid}} = 420, a.\text{requires\_admin\_review} = \text{TRUE}$).
  5. Else $\implies \mathbf{ABSENT}$ ($M_{\text{sched}} = 420, M_{\text{pay}} = 0, M_{\text{unpaid}} = 420$).

  **Mathematical Proof of Non-Double-Deduction:**
  - Let $M_{\text{std}} = \sum_{d \in D} M_{\text{sched}}(d) = N_{\text{sched}} \times 420$.
  - Monthly earned regular salary $S_{\text{earned}}$ is derived strictly as a positive accumulation of verified payable minutes:
    $$S_{\text{earned}} = \text{ROUND}\left( \frac{\sum_{d \in D} M_{\text{pay}}(d)}{M_{\text{std}}} \times \text{monthly\_salary\_reference\_paise} \right)$$
  - Because absences, leaves, and incomplete pairs produce $M_{\text{pay}}(d) = 0$, unworked minutes are not subtracted as negative deductions from base pay. They simply contribute 0 to the numerator.
  - Line-item deductions (`employee_payroll_adjustments`) are reserved strictly for external recoveries, advances, and statutory withholdings.
  - **Conclusion:** Double deduction is mathematically and architecturally impossible.

### Finding A7: Unified Global Concurrency Lock Hierarchy ($L_0 \to L_4$)
- **Defect Identified:** Prior revisions lacked formal proofs covering all 7 source writers.
- **Hierarchy Definition:** Every database mutation must acquire row-level locks strictly in top-down order to eliminate deadlocks:
  - **$L_0$ (`organizations`):** Acquired `FOR SHARE` on tenant-wide configuration modifications.
  - **$L_1$ (`payroll_periods`):**
    - All operational attendance/leave writers acquire **`FOR SHARE OF payroll_periods`**.
    - Payroll compilation and approval acquire **`FOR UPDATE OF payroll_periods`**.
  - **$L_2$ (`employees`):** Acquired `FOR SHARE` (or `FOR UPDATE` on salary/roster mutations) ordered by `employee_id ASC`.
  - **$L_3$ (`attendance_days`):** Acquired `FOR UPDATE` ordered by `attendance_date ASC`.
  - **$L_4$ (Child records):** `attendance_events`, `attendance_corrections`, `leave_applications`, `employee_payroll_adjustments`.

- **Coverage Across All 7 Writer Paths:**
  1. *Biometric Punch Writer (`record_attendance_punch`):* Acquires $L_1$ (`FOR SHARE pp`), then $L_3$ (`FOR UPDATE ad`), then writes $L_4$ (`attendance_events`).
  2. *Attendance Correction Writer (`submit_attendance_correction`):* Acquires $L_1$ (`FOR SHARE pp`), then $L_3$ (`FOR UPDATE ad`), writes $L_4$ (`attendance_corrections`), updates $L_3$.
  3. *Leave Application Approval:* Acquires $L_1$ (`FOR SHARE pp`), then $L_2$ (`FOR SHARE emp`), then writes $L_4$ (`leave_applications`).
  4. *Salary Revision Insertion:* Acquires $L_1$ (`FOR SHARE pp`), then $L_2$ (`FOR UPDATE emp`), then writes $L_4$ (`employee_salaries`).
  5. *Payroll Adjustment Insertion:* Acquires $L_1$ (`FOR SHARE pp`), then $L_2$ (`FOR SHARE emp`), then writes $L_4$ (`employee_payroll_adjustments`).
  6. *Payroll Recompile Procedure (`recompile_payroll_run`):* Acquires $L_1$ (`FOR UPDATE pp`), recalculates aggregates, writes `payroll_runs` and `payroll_items`.
  7. *Payroll Freeze & Approval (`approve_payroll_run`):*
     - Step 1: Acquires $L_1$ (`FOR UPDATE pp`).
     - Step 2: Regenerates SDCS hash $H_{\text{live}}$ and compares with run snapshot hash.
     - Step 3: Sets `pp.is_closed = TRUE`.
     - Step 4: Updates `payroll_runs.status = 'APPROVED'`. Commit.
  - **Concurrency Proof:** Because writers 1–5 must acquire $L_1$ `FOR SHARE`, any active writer blocks payroll approval. Conversely, once payroll approval acquires $L_1$ `FOR UPDATE`, all incoming writers are queued. Once committed, writers unblock, observe `is_closed = TRUE`, and abort with `SQLSTATE 55000`.

### Finding B4: Threat Model for Database GUC Manipulation vs Defense-in-Depth
- **Threat Vector:** If an attacker executes arbitrary SQL as runtime database user `hrms_app_user`, they could attempt to call `SELECT set_config('app.current_org_id', 'victim_org_uuid', false);`.
- **Why GUCs Alone Are Not an Authentication Boundary:** GUCs are session variables writable by the database connection.
- **Engine-Level Defense-in-Depth:**
  1. **Direct DML Revocation:** `hrms_app_user` has direct `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE` revoked on all operational tables. Even if GUCs are altered, the attacker cannot write data via raw SQL.
  2. **Stored Routine Authorization:** All writes execute through `SECURITY DEFINER` routines. These routines do not trust GUCs alone; they accept cryptographic JWT claims verified by the Express gateway, perform explicit tenant parameter checks, and validate caller roles against database catalog tables.
  3. **Network Boundary Isolation:** Port 5432 is strictly private within a VPC; zero direct client access.

## 6. DOMAIN D — ATTENDANCE CORRECTIONS

### Finding D1–D7: Hardened `submit_attendance_correction` Procedure
- Complete PL/pgSQL implementation enforcing office timezone, pre-18:00 cutoff, bounded post-18:00 overtime, DEC-02 single-pair rule, and fail-closed error handling:

```sql
CREATE OR REPLACE PROCEDURE public.submit_attendance_correction(
  p_organization_id UUID,
  p_attendance_day_id UUID,
  p_employee_id UUID,
  p_action_type public.punch_type_enum,
  p_corrected_timestamp TIMESTAMPTZ,
  p_reason TEXT,
  p_admin_user_id UUID,
  INOUT p_correction_id UUID DEFAULT NULL
)
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = pg_catalog, public
AS $$
DECLARE
  v_session_org TEXT;
  v_session_user TEXT;
  v_session_role TEXT;
  v_day RECORD;
  v_period RECORD;
  v_office_tz TEXT;
  v_local_date DATE;
  v_in TIMESTAMPTZ;
  v_out TIMESTAMPTZ;
  v_gross_elapsed INT := 0;
  v_lunch_deducted INT := 0;
  v_pre18_elapsed INT := 0;
  v_net_payable INT := 0;
  v_lunch_start TIMESTAMPTZ;
  v_lunch_end TIMESTAMPTZ;
  v_cutoff_18 TIMESTAMPTZ;
  v_max_possible_post18 INT := 0;
  v_new_status public.attendance_day_status_enum;
  v_is_admin BOOLEAN := FALSE;
BEGIN
  -- 1. Validate caller session context
  v_session_org := current_setting('app.current_org_id', true);
  v_session_user := current_setting('app.current_user_id', true);
  v_session_role := current_setting('app.current_user_role', true);

  IF v_session_org IS NULL OR v_session_org::uuid <> p_organization_id THEN
    RAISE EXCEPTION 'Unauthorized tenant context' USING ERRCODE = '42501';
  END IF;

  -- 2. Independent Admin Authorization Check
  SELECT EXISTS (
    SELECT 1 FROM public.user_roles ur
    JOIN public.users u ON u.id = ur.user_id
    WHERE u.id = p_admin_user_id 
      AND u.organization_id = p_organization_id
      AND u.is_active = TRUE
      AND ur.role IN ('ADMIN', 'SUPER_ADMIN')
  ) INTO v_is_admin;

  IF NOT v_is_admin THEN
    RAISE EXCEPTION 'Forbidden: Independent Admin verification failed' USING ERRCODE = '42501';
  END IF;

  IF p_reason IS NULL OR trim(p_reason) = '' THEN
    RAISE EXCEPTION 'Correction reason is mandatory' USING ERRCODE = 'P0001';
  END IF;

  IF p_corrected_timestamp > now() THEN
    RAISE EXCEPTION 'Future timestamps strictly prohibited: %', p_corrected_timestamp USING ERRCODE = '22008';
  END IF;

  -- 3. ACQUIRE L1 PERIOD LOCK (FOR SHARE)
  SELECT pp.id, pp.is_closed INTO v_period
  FROM public.attendance_days ad_lookup
  JOIN public.payroll_periods pp 
    ON pp.organization_id = p_organization_id 
   AND ad_lookup.attendance_date BETWEEN pp.start_date AND pp.end_date
  WHERE ad_lookup.id = p_attendance_day_id
  FOR SHARE OF pp;

  IF NOT FOUND THEN
    RAISE EXCEPTION 'Attendance day % is not mapped to an active payroll period', p_attendance_day_id USING ERRCODE = 'P0002';
  END IF;

  IF v_period.is_closed THEN
    RAISE EXCEPTION 'Payroll period is frozen. Corrections prohibited.' USING ERRCODE = '55000';
  END IF;

  -- 4. ACQUIRE L3 ROW LOCK & RE-READ ATTENDANCE DAY
  SELECT ad.id, ad.organization_id, ad.employee_id, ad.office_id, ad.attendance_date, 
         ad.first_check_in_at, ad.last_check_out_at, ad.approved_post18_minutes
  INTO v_day
  FROM public.attendance_days ad
  WHERE ad.id = p_attendance_day_id AND ad.organization_id = p_organization_id
  FOR UPDATE;

  IF NOT FOUND OR v_day.employee_id <> p_employee_id THEN
    RAISE EXCEPTION 'Attendance day not found or employee mismatch' USING ERRCODE = 'P0002';
  END IF;

  -- 5. RESOLVE OFFICE TIMEZONE (Fail closed on missing timezone)
  SELECT o.timezone INTO v_office_tz
  FROM public.offices o
  WHERE o.id = v_day.office_id AND o.organization_id = p_organization_id AND o.is_active = TRUE;

  IF v_office_tz IS NULL OR trim(v_office_tz) = '' THEN
    RAISE EXCEPTION 'Office timezone could not be resolved for office %', v_day.office_id USING ERRCODE = '22023';
  END IF;

  v_local_date := (p_corrected_timestamp AT TIME ZONE v_office_tz)::date;
  IF v_local_date <> v_day.attendance_date THEN
    RAISE EXCEPTION 'Timestamp local date (%) does not match attendance date (%) in timezone %',
      v_local_date, v_day.attendance_date, v_office_tz USING ERRCODE = '22008';
  END IF;

  -- 6. RECORD IMMUTABLE AUDIT ENTRY
  INSERT INTO public.attendance_corrections (
    organization_id, attendance_day_id, employee_id, action_type, corrected_timestamp, reason,
    previous_state, updated_state, created_by, created_at
  ) VALUES (
    p_organization_id, p_attendance_day_id, p_employee_id, p_action_type, p_corrected_timestamp, trim(p_reason),
    jsonb_build_object('first_check_in_at', v_day.first_check_in_at, 'last_check_out_at', v_day.last_check_out_at),
    jsonb_build_object('action_type', p_action_type, 'corrected_timestamp', p_corrected_timestamp),
    p_admin_user_id, now()
  ) RETURNING id INTO p_correction_id;

  -- 7. RECONCILE TIMESTAMPS
  IF p_action_type = 'CHECK_IN' THEN
    v_in := p_corrected_timestamp;
    v_out := v_day.last_check_out_at;
  ELSIF p_action_type = 'CHECK_OUT' THEN
    v_in := v_day.first_check_in_at;
    v_out := p_corrected_timestamp;
  END IF;

  -- 8. AGGREGATE RECALCULATION & BOUNDED POST-18:00
  IF v_in IS NOT NULL AND v_out IS NOT NULL AND v_out > v_in THEN
    v_gross_elapsed := ROUND(EXTRACT(EPOCH FROM (v_out - v_in)) / 60.0)::int;
    
    v_lunch_start := (v_day.attendance_date::text || ' 13:00:00')::timestamp AT TIME ZONE v_office_tz;
    v_lunch_end   := (v_day.attendance_date::text || ' 14:00:00')::timestamp AT TIME ZONE v_office_tz;
    v_cutoff_18   := (v_day.attendance_date::text || ' 18:00:00')::timestamp AT TIME ZONE v_office_tz;

    -- Lunch deduction clipping
    IF v_in < v_lunch_end AND v_out > v_lunch_start THEN
      v_lunch_deducted := ROUND(EXTRACT(EPOCH FROM (LEAST(v_out, v_lunch_end) - GREATEST(v_in, v_lunch_start))) / 60.0)::int;
      v_lunch_deducted := GREATEST(0, LEAST(60, v_lunch_deducted));
    ELSE
      v_lunch_deducted := 0;
    END IF;

    -- Standard core minutes up to 18:00
    v_pre18_elapsed := ROUND(EXTRACT(EPOCH FROM (LEAST(v_out, v_cutoff_18) - v_in)) / 60.0)::int;
    v_net_payable := GREATEST(0, v_pre18_elapsed - v_lunch_deducted);

    -- Bound post-18 work strictly by physical presence after 18:00
    IF v_out > v_cutoff_18 THEN
      v_max_possible_post18 := ROUND(EXTRACT(EPOCH FROM (v_out - v_cutoff_18)) / 60.0)::int;
      v_net_payable := v_net_payable + LEAST(v_max_possible_post18, COALESCE(v_day.approved_post18_minutes, 0));
    END IF;

    v_new_status := 'PRESENT'::public.attendance_day_status_enum;
  ELSE
    -- DEC-02: Incomplete or inverted pair produces ZERO payable minutes and flags review
    v_gross_elapsed := 0;
    v_lunch_deducted := 0;
    v_net_payable := 0;
    v_new_status := 'INCOMPLETE_PAIR'::public.attendance_day_status_enum;
  END IF;

  -- 9. UPDATE ATTENDANCE DAY
  UPDATE public.attendance_days
  SET first_check_in_at = v_in,
      last_check_out_at = v_out,
      gross_elapsed_minutes = v_gross_elapsed,
      lunch_deducted_minutes = v_lunch_deducted,
      net_payable_minutes = v_net_payable,
      day_status = v_new_status,
      requires_admin_review = (v_in IS NOT NULL AND v_out IS NULL) OR (v_in IS NULL AND v_out IS NOT NULL) OR (v_in >= v_out),
      reviewed_by = p_admin_user_id,
      reviewed_at = now(),
      review_reason = trim(p_reason),
      updated_at = now()
  WHERE id = p_attendance_day_id;
END;
$$;
```

  import { Pool, PoolClient } from 'pg';
  import jwt, { JwtHeader, SigningKeyCallback } from 'jsonwebtoken';
  import jwksClient from 'jwks-rsa';

  const dbPool = new Pool({
    connectionString: process.env.DATABASE_URL,
    max: 50,
    idleTimeoutMillis: 30000,
  });

  const RFC4122_UUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i;

  // Asymmetric JWKS client configuration
  const jwks = jwksClient({
    jwksUri: `${process.env.SUPABASE_URL}/auth/v1/.well-known/jwks.json`,
    cache: true,
    cacheMaxEntries: 5,
    cacheMaxAge: 600000, // 10 minutes
    rateLimit: true,
    jwksRequestsPerMinute: 10,
  });

  function getSigningKey(header: JwtHeader, callback: SigningKeyCallback) {
    if (header.alg === 'HS256') {
      const secret = process.env.SUPABASE_JWT_SECRET;
      if (!secret || Buffer.byteLength(secret, 'utf8') < 32) {
        return callback(new Error('SECURITY_CONFIG_ERROR: HS256 secret must be at least 32 bytes'));
      }
      return callback(null, secret);
    }

    jwks.getSigningKey(header.kid, (err, key) => {
      if (err) return callback(err);
      callback(null, key?.getPublicKey());
    });
  }

  export async function executeTenantTransaction<T>(
    rawJwtToken: string,
    callback: (client: PoolClient, context: { userId: string; orgId: string; role: string }) => Promise<T>
  ): Promise<T> {
    return new Promise((resolve, reject) => {
      jwt.verify(
        rawJwtToken,
        getSigningKey,
        {
          algorithms: ['RS256', 'ES256', 'HS256'],
          issuer: process.env.SUPABASE_JWT_ISSUER,
          audience: 'authenticated',
        },
        async (verifyErr, decoded: any) => {
          if (verifyErr || !decoded || !RFC4122_UUID_REGEX.test(decoded.sub)) {
            return reject(new Error('AUTH_FAILED: Invalid JWT signature, issuer, or subject UUID'));
          }

          const client = await dbPool.connect();
          let isReleased = false;

          try {
            await client.query('BEGIN');
            await client.query("SET LOCAL lock_timeout = '3s'; SET LOCAL statement_timeout = '5s';");

            const ctxRes = await client.query(
              'SELECT user_id, organization_id, primary_role, is_active, org_active FROM public.resolve_user_auth_context($1)',
              [decoded.sub]
            );
            const user = ctxRes.rows[0];
            if (!user || !user.is_active || !user.org_active) {
              throw new Error('AUTH_DENIED: Inactive account or organization');
            }

            await client.query(
              `SELECT set_config('app.current_user_id', $1, true),
                      set_config('app.current_org_id', $2, true),
                      set_config('app.current_user_role', $3, true)`,
              [user.user_id, user.organization_id, user.primary_role]
            );

            const result = await callback(client, {
              userId: user.user_id,
              orgId: user.organization_id,
              role: user.primary_role,
            });

            await client.query('COMMIT');
            resolve(result);
          } catch (txErr) {
            try {
              await client.query('ROLLBACK');
            } catch (rbErr) {
              if (!isReleased) {
                isReleased = true;
                client.release(rbErr); // Destroy contaminated socket
              }
              return reject(txErr);
            }
            reject(txErr);
          } finally {
            if (!isReleased) {
              isReleased = true;
              try {
                await client.query('DISCARD SEQUENCES; RESET ALL;');
                client.release();
              } catch (cleanErr) {
                client.release(cleanErr);
              }
            }
          }
        }
      );
    });
  }
